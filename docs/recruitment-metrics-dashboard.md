# 招聘首页真实指标说明

| 指标 | 计算口径 | 数据源 | 空数据值 |
| --- | --- | --- | --- |
| 进行中职位 | 阶段不是 `report` 的招聘项目数 | `projects.stage` | 0 |
| 已评估候选人 | 状态为 `complete` 且存在匹配结果的候选人数 | `snapshot.candidates` | 0 |
| 平均匹配度 | 所有已评估候选人的匹配总分平均值 | `candidate.match.totalScore` | 0 |
| 已完成报告 | 存在面试报告的招聘项目数 | `snapshot.report` | 0 |

“正在进行的招聘”仅展示未完成项目，按最近更新时间倒序排列。职位名称、阶段、候选人数、候选人缩写和最高匹配分均来自 SQLite 项目快照。
